1 · Installation (2 Minuten)

Drei Dateien, kein Build-Step. Tailwind ist optional, verbessert aber das Layout.

A · Dateien kopieren
Lege src/liquid-glass.css und src/liquid-glass.js in dein Projekt.
B · Einbinden
CSS in den <head>, JS ans Ende vom <body>.
C · Klasse nutzen
Z. B. class="glass glass-card" – fertig ist die Glas-Card.
In deinen <head> einfügen
<!-- Tailwind (optional, für Layout) -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- Liquid Glass Kit -->
<link rel="stylesheet" href="src/liquid-glass.css" />
<script src="src/liquid-glass.js" defer></script>
Theme / Dark Mode (optional)
<!-- Hell ist Standard. Für Dunkel: -->
<html data-theme="dark">

<!-- Umschalter irgendwo auf der Seite: -->
<button class="glass-btn" data-lg-theme>
  <span data-lg-theme-label>🌙 Dunkel</span>
</button>
2 · Verwendung – Grundprinzip

Jedes Element = .glass als Basis + eine Komponenten-Klasse. Tailwind-Klassen für Abstände/Layout einfach dazu mischen.

<!-- Einfachste Card -->
<div class="glass glass-card hoverable">
  <h3 class="glass-card-title">Hallo Glas 👋</h3>
  <p class="glass-card-sub">Beschreibung hier.</p>
</div>

<!-- Button -->
<button class="glass-btn glass-btn-primary" onclick="LiquidGlass.toast('Hi','Funktioniert!')">
  Speichern
</button>

<!-- Toast per JS auslösen (Container braucht id="lg-toast-stack") -->
<div class="glass-toast-stack" id="lg-toast-stack"></div>
<script>LiquidGlass.toast('Titel', 'Nachricht', '🔔');</script>
💡 Regel 1: Glas braucht Hintergrund dahinter. Ohne bunten Verlauf/Wallpaper wirkt es flach – nutze .ios-wallpaper oder ein Bild.
💡 Regel 2: Nicht stapeln ohne Maß: max. 2 Glas-Ebenen übereinander, sonst wird Text unleserlich. Nutze dann .glass-strong.

4 · Klassen-Referenz

Alle Klassen auf einen Blick. Kombiniere .glass + Variante + Tailwind.

KlasseWirkung
.glassBasis: Blur, Glanz, Border, Schatten
.glass-strong / .glass-clearStärker deckend / fast durchsichtig
.glass-card + .hoverableInhaltskarte mit Hover-Lift
.glass-btn + -primary / -destructive / -ghost / -sm / -lgPill-Buttons in iOS-Farben
.glass-icon-btn + .activeRunder Icon-Button, aktiv = blau
.glass-tabbar / .glass-tab(.active)Untere iOS-Navigation
.glass-navbarSticky Top-Bar
.glass-segmented button(.active)Segment-Umschalter
.glass-input / .glass-searchTextfeld / runde Suche
.glass-switch(.on)iOS-Toggle (klickbar, Tastatur: Enter/Space)
.glass-sliderGlas-Slider
.glass-chip / .glass-dotPille + Statuspunkt
.glass-tile([data-toggle]) + .activeControl-Center-Kachel
.glass-toast-stack / .glass-toastBenachrichtigungen oben
.glass-overlay / .glass-sheet / .glass-modalSheet & Dialog (mit data-lg-open/close)
.glass-artwork / .glass-progressPlayer-Cover + Fortschritt
.ios-wallpaperFixierter iOS-Farbverlauf als Hintergrund
🎨 Eigene Farbe?
CSS-Variablen überschreiben: --glass-bg, --glass-blue, --glass-radius.
⚡ Events?
glass:switch und glass:segment als CustomEvents auf dem Element.
🖼 Kein Blur?
backdrop-filter braucht Hintergrund dahinter und HTTPS/localhost in manchen Browsern.
